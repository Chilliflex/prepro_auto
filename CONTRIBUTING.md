# Contributing to PrePro Auto

This repository hosts PrePro Auto's documentation, user guide, and examples.
The engine's source is developed privately, so the usual "fork it, fix it,
open a PR" flow doesn't apply here — but your input is still very welcome.

## Quickest ways to help right now

- **Try it on your own dataset** (`pip install prepro-auto`) and
  [open an issue](https://github.com/Chilliflex/prepro_auto/issues) if
  something breaks or behaves unexpectedly.
- **Report a bug** — include your Python version, OS, the exact command you
  ran, and the full traceback.
- **Request a feature** — describe the use case ("I want X so that Y"), not
  just the feature name; that's much more useful than a one-line ask.
- **Suggest a docs fix** — typos, unclear steps, or a missing example are all
  fair game to flag.

## What makes a good issue

- For bugs: Python version, OS, the exact command you ran, the full traceback.
- For features: the use case, not just the feature name.
- For questions: check the [README](README.md) and existing issues first.
